## ✨ About The Project

**Focus on Today** is a minimal and motivating goal tracker that helps users focus on **3 important goals per day**.

It combines productivity with simplicity and motivation.

---

## 🔥 Features

- ✅ 3 Daily Goals Limit
- 📊 Dynamic Progress Bar
- 🔐 Login & Signup Authentication
- 💾 Database Storage
- 🙌 Motivational Quotes
- 🧼 Clean UI
- 🗑️ Delete Goals Option
